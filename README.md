# go-learning

Go 后端学习与实战记录。

## 目标

以 Go 后端开发为主线（Java 为备），积累可展示的工程项目，为 2028 年 3 月首次投递做准备。

## 目录结构

```
.
├── README.md
├── go.mod
├── cmd/                    # 可执行程序入口
│   └── hello/
│       └── main.go
└── internal/               # 项目内部包（不对外暴露）
    └── greet/
        ├── greet.go
        └── greet_test.go
```

### 为什么这样分层

| 目录 | 作用 | 说明 |
|---|---|---|
| `cmd/` | 程序入口 | 每个子目录编译出一个可执行文件。业务逻辑不要写在这里。 |
| `internal/` | 内部实现 | Go 强制约束：`internal` 下的包**只能被本模块引用**，外部模块无法导入。适合放不想对外暴露的实现。 |
| `pkg/` | 可复用库 | 如需对外暴露公共库时才用（当前项目暂不需要，不用提前建）。 |

## 运行

```bash
# 运行 hello 程序
go run ./cmd/hello

# 传入参数
go run ./cmd/hello 你的名字

# 运行全部测试
go test ./...

# 查看测试覆盖率
go test -cover ./...

# 代码格式检查（无输出表示规范）
gofmt -l .

# 静态检查
go vet ./...
```

## 学习方法

按「学一个点 → 写一段代码 → 提交一次」的节奏推进，保证提交历史真实反映学习轨迹。
